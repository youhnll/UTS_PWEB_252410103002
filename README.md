Deskripsi

Keuangan adalah aplikasi web sederhana untuk mencatat pemasukan dan pengeluaran mahasiswa. Pengguna masuk lewat halaman login, lalu melihat ringkasan saldo di dashboard, daftar transaksi di halaman pengelolaan, dan data diri di halaman profile.

Project dibuat dengan Laravel murni (tanpa starter kit dan tanpa template dashboard jadi) memakai arsitektur MVC dan Blade. Sesuai ketentuan UTS, aplikasi tidak memakai database. Semua data berupa array yang disiapkan di Controller.
